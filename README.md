# Krishna Tiwari — Webfolio

A dynamic, interactive personal developer portfolio built for the CMR University Webfolio Challenge. 

This project goes beyond a static HTML page by utilizing a component-driven React architecture, complete with interactive 3D physics, modular data structures, and a modern "Glassmorphism" UI design.

## 🚀 Live Deployment
**Live Demo:** <krishnatiwari-portfolio.vercel.app>

## 🛠️ Tech Stack & Architecture
* **Frontend Framework:** React.js (Bootstrapped with Vite for instant HMR)
* **Styling:** Tailwind CSS (Utility-first, responsive, dark-mode focused)
* **Animations:** Framer Motion (Scroll-triggered fade-ins, 3D card tilt physics)
* **Icons:** Lucide React
* **Data Management:** Fully modular `portfolioData.js` acting as a local JSON data store for scalable content updates.

## ✨ Key Technical Features
* **Bento Box CSS Grid:** A responsive, asymmetrical grid layout highlighting major cloud architectures alongside software and NLP projects.
* **Interactive Modals:** Complex React state management handles accessible, backdrop-blurred overlays for certificate inspection.
* **Smart Contact Dock:** Features clipboard API integration with toast notifications for seamless recruiter contact.

## ⚡ Running Locally
To run this project on your local machine:

1. Clone the repository: 
   `git clone https://github.com/Krishnatiwari1909/webfolio.git`
2. Navigate into the directory: 
   `cd webfolio`
3. Install dependencies: 
   `npm install`
4. Start the development server: 
   `npm run dev`
